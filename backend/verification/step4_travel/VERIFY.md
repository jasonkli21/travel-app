## Reproduction

Run from this directory inside the lane worktree. The expected layout is `step4-travel-lane/pas` and `step4-travel-lane/travel`. The script creates a new PostgreSQL cluster for each run, starts separate TLS and HTTP listeners on ephemeral loopback ports, and stops that cluster afterward. It expects the previously built offline Python environments and PostgreSQL 16.2 binaries, with path overrides through `PAIR_PAS_PYTHON`, `PAIR_TRAVEL_PYTHON` and `PAIR_PG_BIN`. The runtime requires a writable POSIX directory outside any checkout or synthetic `.git` ancestor. This host uses `/dev/shm`. The lane runs with numeric loopback and local sockets available. No private data or live credential is consumed.

```bash
PAIR_PG_PORT=56679 ./run.sh > evidence/paired-run.log 2>&1
PAIR_PG_PORT=56678 PAIR_DISTINCT_OWNER=1 \
  PAIR_EVIDENCE_DIR="$PWD/evidence/distinct-owner" ./run.sh > evidence/distinct-owner-run.log 2>&1
```
